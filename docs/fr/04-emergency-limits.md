# 4. Urgence et limites

Le guardian et la gouvernance peuvent déclencher une pause d’urgence pour suspendre dépôts et rachats. En cas de perte chez le fournisseur de rendement, la priorité de la tranche AA organise la distribution des fonds restants ; elle ne garantit pas que tous les déposants seront remboursés.

Les points de vigilance sont le fournisseur externe, le prix checkpointé, le changement de stratégie, les paramètres de ratio, les permissions de gouvernance et les tokens atypiques. Le dépôt expose un code ancien : son comportement doit être confirmé avant tout usage réel.

Ce chapitre est documentaire. Aucune installation, compilation, exécution ou validation de test n’a été effectuée. Les tests amont sont indiqués comme piste de vérification séparée.
